## Addresses

Interchain Token Service and factory addresses for every connected chain are on [Chains and contracts](/infrastructure/network/chains-and-contracts).

## Contracts

| Contract                                                                                                                                       | Description                                                       |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| [InterchainTokenService](https://github.com/axelarnetwork/interchain-token-service/blob/main/contracts/InterchainTokenService.sol)              | Registers tokens and sends interchain transfers on EVM chains     |
| [InterchainTokenFactory](https://github.com/axelarnetwork/interchain-token-service/blob/main/contracts/InterchainTokenFactory.sol)              | Deploys interchain tokens and registers canonical tokens          |
| [TokenManager](https://github.com/axelarnetwork/interchain-token-service/blob/main/contracts/token-manager/TokenManager.sol)                    | Connects a token to ITS on one chain                              |
| [ITS Hub](https://github.com/axelarnetwork/axelar-amplifier/tree/main/contracts/interchain-token-service)                                       | Routes interchain transfers between chains, on the Axelar network |
