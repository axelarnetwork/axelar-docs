## How to transfer assets now

Use [app.axelar.network](https://app.axelar.network/), Axelar's current interface for cross-chain transfers.

Developers integrating transfers into their own application should start at [Send Tokens](/its/overview), which covers both Gateway tokens and the [Interchain Token Service](/its/overview).

## What Satellite was

Satellite was a web application built on top of the Axelar Network.
It provided an interface for users to transfer their crypto assets from one chain to another, and was the main way to mint Axelar-wrapped assets such as [axlUSDC](/gmp/resources/axlusdc).

It relied on [deposit addresses](/gmp/integrations/evm/send-tokens-with-messages), a transfer route that is now disabled.
