Most repositories are under the [axelarnetwork](https://github.com/axelarnetwork) GitHub organization.

## Axelar chain

| Repository | Description |
| --- | --- |
| [axelar-core](https://github.com/axelarnetwork/axelar-core) | The Axelar chain node: `axelard` and the `vald` validator process. Releases and the [changelog](https://github.com/axelarnetwork/axelar-core/blob/main/CHANGELOG.md) |
| [tofnd](https://github.com/axelarnetwork/tofnd) | gRPC threshold signing service used by `vald` and `ampd` |
| [tofn](https://github.com/axelarnetwork/tofn) | Threshold cryptography library behind `tofnd` |
| [axelarate-community](https://github.com/axelarnetwork/axelarate-community) | Scripts to set up and join the network as a node or validator |
| [axelarjs-types](https://github.com/axelarnetwork/axelarjs-types) | TypeScript types for Axelar's Protocol Buffers |

## Amplifier Protocol

| Repository | Description |
| --- | --- |
| [axelar-amplifier](https://github.com/axelarnetwork/axelar-amplifier) | Amplifier CosmWasm contracts, `ampd` and the chain handlers. [Changelog](https://github.com/axelarnetwork/axelar-amplifier/blob/main/CHANGELOG.md) |
| [ampd-proto](https://github.com/axelarnetwork/ampd-proto) | Protobuf definitions for the `ampd` gRPC interface used by handlers |
| [amplifier-relayer-api](https://github.com/axelarnetwork/amplifier-relayer-api) | API schema and client for the Amplifier Relayer API |
