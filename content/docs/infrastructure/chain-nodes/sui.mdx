Instructions to set up your Sui node.

### Requirements

- [Set up your Amplifier verifier](/infrastructure/verifiers/amplifier/verifier-onboarding)
- Minimum hardware requirements: CPUs: 8 physical cores / 16 vCPUs RAM: 128 GB Storage (SSD): 4 TB NVMe drive
- Ubuntu 22.04
- [Official Documentation](https://docs.sui.io/operators/full-node/sui-full-node)

### Prerequisites

The steps below assume your user has `sudo` permissions. To verify the node at the end, install [grpcurl](https://github.com/fullstorydev/grpcurl).

### Install Sui

Download the release archive for your network from the [Sui releases page](https://github.com/MystenLabs/sui/releases). The tags below are examples; use the latest `mainnet-*` or `testnet-*` release.

<Tabs items={["Mainnet","Testnet"]}>
  <Tab value="Mainnet">
    ```bash
    SUI_TAG=mainnet-v1.82.3
    ```
  </Tab>
  <Tab value="Testnet">
    ```bash
    SUI_TAG=testnet-v1.83.0
    ```
  </Tab>
</Tabs>

The archive contains `sui-node`, `sui`, and `sui-tool` (needed for the snapshot step below):

```bash
cd $HOME
mkdir -p sui-binaries && cd sui-binaries

# Linux x86_64 (use ubuntu-aarch64 for ARM)
wget https://github.com/MystenLabs/sui/releases/download/$SUI_TAG/sui-$SUI_TAG-ubuntu-x86_64.tgz
tar -xzf sui-$SUI_TAG-ubuntu-x86_64.tgz
sudo install -m 755 $(find . -type f \( -name sui-node -o -name sui -o -name sui-tool \)) /usr/local/bin/

# verify version
sui-node --version
sui-tool --version
cd $HOME
```

<Callout title="Ports">
  The node serves its gRPC API on port `9000`, set by `json-rpc-address` in
  `fullnode.yaml` (the key keeps its old name; JSON-RPC itself has been removed
  from Sui full nodes). This is the endpoint the ampd `sui-handler` connects to.
  Open UDP port `8084` for P2P state sync. The template binds metrics to
  `0.0.0.0:9184`; consider changing `metrics-address` to `127.0.0.1:9184`.
</Callout>

Download the snapshot from the latest epoch.

<Tabs items={["Mainnet","Testnet"]}>
  <Tab value="Mainnet">
    ```bash
    sui-tool download-formal-snapshot --latest --genesis /opt/sui/config/genesis.blob --network mainnet --path /opt/sui/db/ --num-parallel-downloads 50 --no-sign-request
    ```
  </Tab>
  <Tab value="Testnet">
    ```bash
    sui-tool download-formal-snapshot --latest --genesis /opt/sui/config/genesis.blob --network testnet --path /opt/sui/db/ --num-parallel-downloads 50 --no-sign-request
    ```
  </Tab>
</Tabs>

If you encounter any failures, try lowering the `num-parallel-downloads` value.

Formal snapshots contain no transaction history from before the snapshot, so the node can't serve lookups of older transactions. See [Sui snapshots](https://docs.sui.io/guides/operator/snapshots) for details.

### Setup systemd

Create the systemd service file `/etc/systemd/system/suid.service`

```bash
sudo tee /etc/systemd/system/suid.service &>/dev/null <<EOF
[Unit]
Description=Sui Node
After=network-online.target
Wants=network-online.target

[Service]
User=$USER
WorkingDirectory=/opt/sui/
Environment=RUST_LOG=info,sui_core=debug,consensus=debug,jsonrpsee=error
ExecStart=/usr/local/bin/sui-node --config-path /opt/sui/config/fullnode.yaml
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF
```

### Start the service

```bash
sudo systemctl daemon-reload
sudo systemctl enable suid
sudo systemctl restart suid
```

### Check logs

```bash
# change log settings to persistent if not already
sudo sed -i 's/#Storage=auto/Storage=persistent/g' /etc/systemd/journald.conf
sudo systemctl restart systemd-journald
journalctl -u suid.service -f -n 100 -o cat
```

On startup, the logs should show the P2P network, discovery, and state sync starting without errors.

## Verify RPC

Once your `sui` node is fully synced, query its gRPC API with [grpcurl](https://github.com/fullstorydev/grpcurl):

```bash
grpcurl -plaintext localhost:9000 sui.rpc.v2.LedgerService/GetServiceInfo
```

The response includes the chain name, current epoch, and latest checkpoint height. Compare the epoch and checkpoint with the [explorer](https://suiscan.xyz).

Create a config directory for the `sui-handler`, pointing it at your node:

```toml title="~/.ampd/sui/config.toml"
ampd_url = "http://127.0.0.1:9090"
chain_name = "sui"
```

```toml title="~/.ampd/sui/sui-handler-config.toml"
rpc_url = "http://<your-node-host>:9000" # your node's gRPC endpoint
```

Start the handler:

```bash
sui-handler --config-dir ~/.ampd/sui/
```

See [Set up handlers](/infrastructure/verifiers/amplifier/verifier-onboarding#set-up-handlers) for running handlers with Docker or as services.

## Register chain support

Once the handler is running, register your verifier's support for the chain:

```bash
ampd register-chain-support amplifier sui
```
