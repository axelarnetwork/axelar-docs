title: "Axelar for Developers"
---

Axelar enables secure token transfers and communication across different blockchains, regardless of consensus mechanisms or message payloads. It’s based on the same [proof-of-stake security model](/infrastructure/resources/security#proof-of-stake-consensus) as many of the chains it connects. Interchain apps built on Axelar are truly permissionless: their transactions cannot be censored by any oracle, relayer, or validator.

To make an interchain transaction with Axelar:

1. Call the Gateway contract method on the source chain:
   - [`callContract()`](/gmp/evm/gmp-messages) to send messages without tokens.
   - [`callContractWithToken()`](/gmp/evm/gmp-tokens-with-messages) to send messages along with a [gateway token](/its/token-transfer-overview#gateway-tokens).
1. Pay gas to the [`AxelarGasService`](/gmp/gas-service/intro) contract on the source chain.

You can then use [Axelarscan](/gmp/products-overview#check-interchain-transactions), Axelar’s dedicated blockchain explorer, to execute, recover, or check the status of your transaction.

## Tools and resources

- [`axelar-examples`](https://github.com/axelarnetwork/axelar-examples) – Cross-chain sample apps using Axelar that can be executed locally or deployed to testnets
- [`foundry-axelar-gmp-example`](https://github.com/axelarnetwork/foundry-axelar-gmp-example) – A sample app that integrates with [Axelar GMP](/gmp/overview) using the [Foundry](https://github.com/foundry-rs/foundry) framework
- [AxelarJS SDK](/gmp/axelarjs-sdk/intro) – an [npm](https://www.npmjs.com/package/@axelar-network/axelarjs-sdk/) library with a collection of APIs and query tools
- [`axelar-local-dev`](https://github.com/axelarnetwork/axelar-local-dev) – A local cross-chain development environment where you can deploy an app to simulated EVM chains. These chains are preloaded with the [`AxelarGateway`](https://github.com/axelarnetwork/axelar-cgp-solidity/blob/main/contracts/AxelarGateway.sol), `AxelarGasReceiver`, and routed ERC-20 (axlUSDC) token contracts. Deployed apps can be tested against the RPC endpoints and contract addresses of your local development environment.
