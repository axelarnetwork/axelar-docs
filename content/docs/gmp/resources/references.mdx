## Addresses

Gateway, gas service and ITS addresses for every connected chain are on [Chains and contracts](/infrastructure/network/chains-and-contracts).

## Contracts

| Contract | Description |
| --- | --- |
| [AxelarGateway](https://github.com/axelarnetwork/axelar-cgp-solidity/blob/main/contracts/AxelarGateway.sol) | Gateway on consensus EVM chains: `callContract`, `callContractWithToken` and message approval |
| [AxelarAmplifierGateway](https://github.com/axelarnetwork/axelar-gmp-sdk-solidity/blob/main/contracts/gateway/AxelarAmplifierGateway.sol) | Gateway on Amplifier EVM chains |
| [AxelarGasService](https://github.com/axelarnetwork/axelar-cgp-solidity/blob/main/contracts/gas-service/AxelarGasService.sol) | Gas payments, gas top-ups and refunds |
| [AxelarExecutable](https://github.com/axelarnetwork/axelar-gmp-sdk-solidity/blob/main/contracts/executable/AxelarExecutable.sol) | Base contract for receiving messages |
| [AxelarExpressExecutableWithToken](https://github.com/axelarnetwork/axelar-gmp-sdk-solidity/blob/main/contracts/express/AxelarExpressExecutableWithToken.sol) | Base contract for receiving messages with [Express](/gmp/integrations/evm/express) |
| [AxelarValuedExpressExecutable](https://github.com/axelarnetwork/axelar-gmp-sdk-solidity/blob/main/contracts/express/AxelarValuedExpressExecutable.sol) | Express for messages whose value is computed by the contract |
