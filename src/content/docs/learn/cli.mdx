# Axelar command-line interface (CLI)

import { Callout } from "/src/components/callout";

Some CLI commands require access to a fully synced Axelar node. Learn how to [start your own Axelar node](/node/join).

Some CLI commands require AXL tokens to pay for on-chain transaction fees. Get testnet AXL tokens from the Axelar faucets: [testnet](https://faucet.testnet.axelar.dev/).

<Callout type="error" emoji="🔥">
  The CLI-based cross-chain token transfer guides below are **disabled**. They relied on the link-deposit protocol, which was removed in the [v1.4 network upgrade](/resources/mainnet/upgrades/v147/). They are retained for historical reference only — to transfer tokens across chains today, use the [Interchain Token Service](/dev/send-tokens/interchain-tokens/intro/).
</Callout>

The following guides describe the legacy CLI-based cross-chain token transfer flows (now disabled):

- [Send UST to an EVM chain](/learn/cli/ust-to-evm/)
- [Redeem UST from an EVM chain](/learn/cli/ust-from-evm/)
- [Send AXL to an EVM chain](/learn/cli/axl-to-evm/)
- [Redeem AXL from an EVM chain](/learn/cli/axl-from-evm/)

In addition to the Axelar-specific CLI features mentioned above, Axelar also offers the same basic set of CLI commands as any other Cosmos SDK project.

View the [full CLI documentation](https://github.com/axelarnetwork/axelar-core/blob/main/docs/cli/toc.md) for the latest node version, or choose a specific version:

<Callout emoji="💡"  longConent>

<br/>

```bash
--gas=auto --gas-adjustment=1.5
```

</Callout>
