# Redeem AXL from an EVM chain (Disabled)

import { Callout } from "/src/components/callout";

<Callout type="error" emoji="🔥">
  This CLI transfer flow is **disabled**. The legacy link-deposit protocol it relied on (`axelard tx evm link` / `latest-deposit-address`) was removed in the [v1.4 network upgrade](/resources/mainnet/upgrades/v147/). Do not attempt it — tokens sent to a generated deposit address are not relayed and may be permanently lost.

To move tokens across chains today, use the [Interchain Token Service](/dev/send-tokens/interchain-tokens/intro/).

</Callout>

This page is retained for historical reference only.

This guide previously described how to redeem AXL tokens from an EVM chain back to Axelar using the node CLI.
The flow linked the Axelar destination account to a temporary, one-time deposit address on the EVM chain, had the user send the wrapped AXL ERC-20 to that deposit address, and relied on Axelar's relayers (or a series of manual `axelard` commands) to confirm the deposit and credit the AXL on Axelar.
