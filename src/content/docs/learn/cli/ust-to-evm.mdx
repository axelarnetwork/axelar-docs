# Send UST to an EVM chain (Disabled)

import { Callout } from "/src/components/callout";

<Callout type="error" emoji="🔥">
  This CLI transfer flow is **disabled**. The legacy link-deposit protocol it relied on (`axelard tx axelarnet link` / `latest-deposit-address`) was removed in the [v1.4 network upgrade](/resources/mainnet/upgrades/v147/), and UST/Terra is no longer supported. Do not attempt it — tokens sent to a generated deposit address are not relayed and may be permanently lost.

To move tokens across chains today, use the [Interchain Token Service](/dev/send-tokens/interchain-tokens/intro/).

</Callout>

This page is retained for historical reference only.

This guide previously described how to transfer UST tokens from Terra to an EVM chain using the node CLI.
The flow linked the destination EVM address to a temporary, one-time deposit address on Axelar, had the user send UST to that deposit address over IBC, and relied on Axelar's relayers (or a series of manual `axelard` commands) to confirm the deposit and release the wrapped UST on the destination chain.
